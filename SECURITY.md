# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within TokenGuard or notice that a critical secret pattern is missed, please do NOT open a public issue.

Instead, please send an email directly to:
**umutm7944@gmail.com**

Please include:
- A description of the issue or the missed token format.
- Sample dummy token or code snippet reproducing the problem.
- Any suggested fixes.

We will review, patch, and release a fix promptly.
